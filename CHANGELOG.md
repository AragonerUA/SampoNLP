# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.3.0] - 2025-01-21

### Added
- Initial public release
- Core IMDP algorithm implementation
- Rust-accelerated scoring iteration
- Support for Finnish, Estonian, Hungarian, and general Uralic languages
- Automatic threshold detection using Otsu's method
- Comprehensive test suite
- Full English documentation
- CI/CD pipeline
- Academic citation support (CITATION.cff)

### Changed
- Converted all code and documentation to English
- Improved performance with Rust optimization
- Enhanced error handling and logging

## [0.2.0] - 2025-10-11

### Added
- Positional priors for affixes
- Type-support filtering
- Convergence detection

### Changed
- Refactored scoring logic
- Improved initialization

## [0.1.0] - 2025-10-10

### Added
- Initial implementation
- Basic morpheme cleaning pipeline
- Dynamic programming-based decomposition
